# For Blessed 🌻

A little browser game, made with love.

Design your character, wander a pixel-art sunset beach, find six notes hidden across the sand, and reach the one waiting by the shore.

**Play it:** https://kaizweeen.github.io/for-blessed/

Built as a single self-contained HTML file: no build step, no dependencies, works offline. Keyboard (arrows / WASD) or on-screen touch controls.
